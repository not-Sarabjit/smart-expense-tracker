# Architecture Decision Records

Short documents that capture one significant decision each: the context, what we chose,
what we rejected and why, and the consequences. They are immutable once accepted — to
change a decision, add a new ADR that supersedes the old one.

## Template

```markdown
# ADR NNNN — <title>

- **Status:** Proposed | Accepted | Superseded by ADR NNNN
- **Date:** YYYY-MM-DD

## Context
## Decision
## Alternatives considered
## Consequences
```
